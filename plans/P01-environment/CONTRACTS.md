## 3. `Makefile` targets

| Target | Does |
|---|---|
| `env` | create `.venv` from `python3` if absent; install both lock files with `--require-hashes`; `pip check` |
| `env-offline` | the same, with `--no-index --find-links wheelhouse/` |
| `env-check` | `HF_HOME=.hf TORCH_HOME=.torch HF_HUB_OFFLINE=1 .venv/bin/pytest -m env` |
| `lint` | `.venv/bin/ruff check src tools tests` and `.venv/bin/mypy` |
| `check` | the existing steps, run with `.venv/bin/python`, plus `lint` |

Existing targets keep working. Use `.venv/bin/...` explicitly; do not rely on an activated shell.

## 4. `reports/env/<YYYY-MM-DD>-environment.md`

Generated by `tools/env_report.py`, never hand-written. Fields:

- Python version; `pip check` result
- torch version, CUDA version torch was built with, `torch.cuda.is_available()`, device name, total
  device memory
- torchvision, anomalib, lightning, timm, numpy, pillow versions
- OpenCV version and whether it has a GUI backend (from `cv2.getBuildInformation()`); the name of the
  installed OpenCV distribution(s) — exactly one, and headless
- tkinter / Tk version
- **R17** — which cache received the backbone (`.hf`, `.torch`, or both), each file's path relative to
  the repo and its SHA-256, and the source identifier if the library exposes it
- **R18** — `inspect.signature` of `anomalib.models.image.patchcore.torch_model.PatchcoreModel.__init__`
  and of the Lightning `Patchcore.__init__`, and a one-line conclusion: which of them accepts
  `pre_processor` / `post_processor`
- whether `v4l2-ctl` is on the PATH

## 5. `tests/test_env.py` — all marked `env`

1. `torch.cuda.is_available()` is True, and the device name contains `3050`.
2. Exactly one OpenCV distribution is installed and it is `opencv-python-headless`.
3. `import tkinter` works and `tkinter.TkVersion >= 8.6`.
4. **Offline backbone load:** with `HF_HUB_OFFLINE=1`, `HF_HOME` and `TORCH_HOME` pointing at the repo
   caches, and a fixture that makes `socket.socket.connect` raise, building the pretrained PatchCore
   torch model succeeds.
5. The same, with the caches pointed at an empty temporary directory, **fails** — proving test 4
   really used the cache.

Tests not marked `env` must not import torch or anomalib, so `make check` stays fast and GPU-free.
