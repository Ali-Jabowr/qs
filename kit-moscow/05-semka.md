# 05 · Съёмка датасета на производстве

**Что получится:** ~360 снимков 58 их моти в нашем лайтбоксе — годные, и они же после того, как
мы их сами повредили. По ним Али обучит и проверит модель на *их* продукте.
**Время:** ~30 минут подготовка + 30 минут моти «отдыхают» + ~2 часа съёмка.
**Нужно от производства:** **60 годных моти одного вида** (58 + 2 запасных), одной партии, прямо
с линии, и стол в стороне от линии с розеткой.

Почему так строго — в конце файла. Коротко: **если во время съёмки что-то сдвинулось, снимки всё
равно получатся, модель всё равно обучится — но цифры будут неправдой, и никто этого не заметит.**

---

## Часть А. Датасет

### Шаг 1. Стенд (15 минут)

1. Стол — **в стороне от линии**, не над продуктом на ленте. Не у окна.
2. Лайтбокс на стол. На дно — **чёрный коврик**, приклеить скотчем по краям.
3. **Белый лист** — в левый верхний угол дна, приклеить скотчем. По нему программа следит за светом.
4. **Боковая лампа** — низко, слева, светит вдоль дна (как на стенде у Али). Верхний свет
   лайтбокса **выключен**. Лампа на полную яркость, не приглушённая.
5. Камера — сверху в отверстие, объективом вниз. Закрепить скотчем.
6. Открытую сторону лайтбокса — закрыть **чёрной тканью** во время снимков.
7. **Отметь маркером/скотчем положение лампы и лайтбокса на столе.** С этой минуты до конца
   съёмки ничего из этого не двигается.

### Шаг 2. Ноутбук

Загрузись с SSD (`02-noutbuk.md`), открой терминал, `cd ~/QS`, подключи камеру.

### Шаг 3. Проверка камеры (1 минута)

```
./kit-moscow/kamera.sh
```

Ждать ~30 секунд, ничего не трогать. В конце строки:

- `PASS controls` / `PASS frames` / `PASS read-back` — **должны быть PASS.** Если FAIL —
  `06-esli-problema.md`.
- `reference patch` — может быть FAIL, если свет у тебя не как у Али. **Это не страшно**, если
  число меньше 3%. Если больше — что-то мигает или двигается: закрой ткань, проверь лампу.

### Шаг 4. Пробные снимки и настройка (10 минут)

Положи **одно** годное моти (из запасных) в центр коврика.

```
./kit-moscow/foto.sh proba
```

Напиши подпись `proba1`, Enter. Программа скажет `пересвет X%`. Открой снимок:
`xdg-open data/raw/$(date +%F)-moscow-proba` и посмотри.

| Что видишь | Что сделать |
|---|---|
| `пересвет` больше 1% или моти белое пятно без деталей | Уменьшить `gain` |
| Моти тёмное, крахмал не виден | Увеличить `gain` |
| Снимок размыт | Поменять `focus` (попробовать 30, потом 38) |
| Снимок синеватый / желтоватый | `wb_kelvin`: синий → 4000, жёлтый → 5000 |
| Моти не целиком в кадре | Сдвинуть моти, не камеру |

Как поменять: в терминале `nano kit-moscow/station-moscow.yml` → стрелками к строке `gain:` →
исправить число → **Ctrl+O, Enter** (сохранить) → **Ctrl+X** (выйти). Менять **только** `gain`,
`focus`, `wb_kelvin`. Записать в блокнот: что было, что стало.

Снова `./kit-moscow/foto.sh proba`, снимок, посмотреть. Когда хорошо — пустая строка + Enter,
выход. **Больше ничего не менять до конца съёмки.**

### Шаг 5. План и лотки (10 минут)

```
./kit-moscow/semka.sh
```

Первый запуск составляет **план**: какое моти в какую ячейку и что с ним будет. Открой его:
`xdg-open data/raw/$(date +%F)-moscow/plan.md`.

- Разложи моти по пронумерованным ячейкам: **c01, c02, c03** — три контрольных (отдельно,
  подпиши), затем **1…55**. Лопаткой, в перчатках. **Верх моти не трогать никогда** — отпечаток
  пальца модель посчитает браком, и будет права.
- Ячейки 53–55 — **запасные**: их снимают, только если какое-то моти сломается.
- Пусть моти полежат **30 минут** при комнатной температуре. Если они с холода — **в упаковке /
  под плёнкой**, чтобы не запотели и не подсохли. В это время — вопросы или видео.

### Шаг 6. Съёмка (~2 часа)

```
./kit-moscow/semka.sh
```

Он спросит вид моти, срок годности, время, когда взяли с линии. Откроется окно с картинкой
с камеры и подсказкой сверху. **Подсказки на английском** — словарь ниже.

**Ритм для каждого моти:**
1. Подсказка говорит, какое моти (`u036 · cell 36`) и какой поворот (`0°`).
2. Лопаткой положи моти из этой ячейки в **центр** коврика. Закрой ткань. Руки из кадра.
3. **Пробел** — снимок.
4. Поверни моти лопаткой на ~треть оборота (`120°`), **пробел**. Ещё треть (`240°`), **пробел**.
5. Если моти тестовое — подсказка скажет повредить: **вынь** его, повреди **на доске вне
   лайтбокса** по рецепту, положи обратно, снова 3 поворота.
6. Моти — обратно в его ячейку. Следующее.

**Словарь подсказок:**

| В окне | Значит |
|---|---|
| `control, pass 1/2/3` | Контрольные c01–c03 — снимаются в начале, середине и конце |
| `train` / `calib` | Годное, только 3 поворота |
| `test` | Годное, 3 поворота → повредить → ещё 3 поворота |
| `0° / 120° / 240°` | Поворот: исходно / треть оборота / две трети |
| `good` / `dmg` | Целое / уже повреждённое |
| `dent` | **Вмятина:** круглый кончик колпачка маркера (~10 мм), нажать прямо вниз на ~3 мм, **один раз**, не в центре верха |
| `tear` | **Разрыв:** ножом надрез 5–10 мм через оболочку сверху или сбоку, чуть раздвинуть, чтобы была видна начинка |
| `deformed-flat` | **Сплющить:** плоской крышкой сверху, пока не уйдёт ~треть высоты |
| `deformed-oval` | **Овал:** сжать с двух сторон пальцами (в перчатках) |
| `Brush the floor` | Смести кисточкой крахмал с коврика, затем пробел |
| `placement · empty` | Снимок **пустого** коврика, без моти |
| `placement · edge` | Моти **касается края** чёрного коврика (наполовину за краем) |

**Если ошибся** (рука в кадре, моти сдвинулось, нажал не тот снимок): **не останавливай.**
Запиши в блокнот номер моти и поворот («u022, 120°, рука в кадре») и продолжай. Переснять в
программе нельзя — Али уберёт этот снимок потом.

**Если моти сломалось** до своего снимка: запиши «u022 сломано», возьми запасное из ячейки 53
(потом 54, 55) и снимай его вместо, записав замену.

**Пауза:** можно просто не нажимать пробел. **Q** — полная остановка (снятое сохранится, но
продолжить эту же съёмку нельзя — только если совсем всё плохо).

### Шаг 7. Сразу после — копия

```
./kit-moscow/kopiya.sh
```

На флешку, **до** того как что-то ещё делать. Подробно — `07-sdat.md`.

## Часть Б. Реальный брак (30 минут)

Каждый образец брака, который дадут, — в тот же лайтбокс, при тех же настройках.

```
./kit-moscow/foto.sh brak
```

На каждое моти: положи в центр, закрой ткань, напиши подпись и Enter. Подпись — что это:

```
brak01-vmyatina-vozvrat
brak02-forma-krivaya
brak03-melkiy-razmer
gran01-esche-godnoe      (то, что технолог назвал «ещё годное»)
gran02-uzhe-brak         (то, что технолог назвал «уже брак»)
```

Каждый образец — 3 раза, поворачивая на треть оборота (`brak01-...-0`, `-120`, `-240`).
Пустая строка + Enter — выход. В блокнот: кто дал образец и что о нём сказал.

---

## Почему так строго

- **Камера, лампа, лайтбокс не двигаются** — модель запоминает «как выглядит годное моти при
  *этом* свете». Сдвинул лампу — для модели все моти стали «другими».
- **Повреждать вне лайтбокса** — крошки и крахмал от повреждения не должны лежать рядом со
  следующим моти.
- **Хорошее и повреждённое — с разницей в минуты** — чтобы модель сравнивала моти с самим собой,
  а не утро с вечером.
- **Перчатки и лопатка** — отпечаток на крахмале выглядит как дефект.
- **Порядок случайный, план заранее** — чтобы ни один снимок не попал «куда удобнее».
