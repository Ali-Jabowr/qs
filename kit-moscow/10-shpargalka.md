# 10 · Шпаргалка: команда → результат → что делать

Подробно — `09-komandy.md`. Всё запускать в терминале (**Ctrl+Alt+T**), раскладка **`en`**,
сначала:

```
cd ~/QS
```

Не понял, что на экране → **фото экрана терминала Али**. Ничего не набирать наугад.

---

## 1. Проверка камеры

```
./kit-moscow/kamera.sh
```

Ждать ~30 с, ничего не трогать. Надпись в окне «Switch the room light…» — **не выполнять**.

| Результат | Делать |
|---|---|
| 4 строки `PASS` (controls, frames, read-back, freshness) | ✅ дальше |
| `FAIL reference patch … X%`, X < 3 | ✅ дальше, X в блокнот |
| `FAIL reference patch`, X > 3 | Закрыть ткань, лампа на полную → снова |
| `FAIL controls … MISMATCH` | Камеру отключить, 5 с, подключить → снова |
| `FAIL frames` | Кабель напрямую, другой порт → снова |
| `busy` | Закрыть все окна (Q), браузер → снова |
| Нет `/dev/video0` под C920 | `06`, «Камера не /dev/video0» |

## 2. Пробные снимки / брак / досъёмка

```
./kit-moscow/foto.sh proba        (брак: foto.sh brak · после обрыва: foto.sh dosemka)
```

Подпись латиницей → **Enter** = снимок. **Пустой Enter** = выход.

| Результат | Делать |
|---|---|
| `сохранён 001_… · пересвет 0.xx%` | ✅ |
| `← ПЕРЕСВЕТ` | На пробе: меньше `gain`. Иначе — в блокнот |
| `← белый лист сильно не как на стенде` | Лист в левом верхнем углу? Да → число в блокнот, ✅ |
| `попытка 1: …` и потом `сохранён` | ✅ |
| `НЕ СНЯТО` | Пустой Enter, 10 с, запустить снова |

Посмотреть: `xdg-open data/raw/$(date +%F)-moscow-proba`

## 3. Съёмка

**Первый раз — план:**

```
./kit-moscow/semka.sh
```

| Результат | Делать |
|---|---|
| `ПЛАН ГОТОВ` | Открыть план (`xdg-open …`), разложить моти, ждать 30 мин |

**Второй раз — съёмка:**

```
./kit-moscow/semka.sh
```

Ответы: вид моти → срок `2026-10-27` → **Enter** (время) → `да`.

В окне: **пробел** = снимок / шаг сделан. **Q** = стоп. `drift` держать в ±3%.
На `control, pass 2` → во **2-м терминале** `cd ~/QS` и `./kit-moscow/kopiya.sh`.

| Результат | Делать |
|---|---|
| `Done: N frames …` | ✅ любая клавиша → **kopiya.sh** (телефон — не надо) |
| `drift` больше ±3% | Ткань, лампа, никто не заслоняет → продолжить |
| `… not taken … stopped, frames so far kept` | kopiya.sh → `foto.sh dosemka` по плану (`06`) |
| `уже есть снимки` / `already has frames` | **Не обходить** → `06`, «Съёмка оборвалась» |
| `Input/output error` / окно зависло | `06`, «SSD отключился» |
| Ошибка сразу после вопросов | Опечатка в дате → запустить снова |

## 4. Копия на флешку

```
./kit-moscow/kopiya.sh
```

| Результат | Делать |
|---|---|
| `ГОТОВО: копия совпадает с оригиналом` | ✅ галочка в блокнот |
| `Флешка не найдена` | Files → кликнуть флешку → снова |
| `Номер флешки:` | Номер строки с именем флешки, Enter |
| `КОПИЯ НЕ СОВПАДАЕТ` | Снова; повторилось → другая флешка |
| `No space left` | Другая флешка |

## Порядок дня

```
cd ~/QS
./kit-moscow/kamera.sh        → 4× PASS
./kit-moscow/foto.sh proba    → настроить, пустой Enter
./kit-moscow/semka.sh         → план, разложить, 30 мин
./kit-moscow/semka.sh         → съёмка  (+ kopiya.sh на control, pass 2)
./kit-moscow/kopiya.sh        → ГОТОВО
./kit-moscow/foto.sh brak     → брак
./kit-moscow/kopiya.sh        → ГОТОВО
вечером: видео с телефона → QS/data/raw/<дата>-moscow-telefon/ → kopiya.sh → ГОТОВО
Power Off
```

Нет `ГОТОВО` — **не выключать**.
