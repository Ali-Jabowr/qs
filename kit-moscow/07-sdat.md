# 07 · Что привезти и как отдать

## Сразу после съёмки (на месте)

```
./kit-moscow/kopiya.sh
```

Должно закончиться словом **ГОТОВО: копия совпадает с оригиналом**. Если нет — ещё раз.

## Вечером того же дня

1. Видео и фото с телефона → на SSD: подключи телефон по USB к ноутбуку (на телефоне выбрать
   «Передача файлов»), скопируй их в «Файлах» в папку
   `QS/data/raw/<дата>-moscow-telefon/`.
2. Ещё раз `./kit-moscow/kopiya.sh` — чтобы на флешку ушло и это.
3. Бланк из `03-opros.md` — перепиши/сфотографируй страницы блокнота и положи туда же
   (`<дата>-moscow-telefon/blank-*.jpg`).

## Что везём Али

- [ ] **SSD** — оригинал всего
- [ ] **Флешка** — копия. Везти **отдельно** от SSD (SSD в сумке, флешку в кармане)
- [ ] Заполненный бланк (`03-opros.md`) + блокнот с пометками о съёмке (ошибки, замены, что
  меняли в настройках)
- [ ] Образцы брака в термосумке, если отдали — подписанные
- [ ] Контакты: технолог, ответственный за ХАССП

## Чего не делать

- **Не отправлять** снимки и видео в Telegram / WhatsApp / почту / облако — даже Али. Только
  SSD и флешка из рук в руки. Если Али срочно нужно увидеть один кадр — договориться с ним.
- Не удалять ничего с SSD, даже «неудачные» снимки — Али разберёт сам.
- Не открывать снимки в редакторах и не сохранять их заново (это меняет файл).

## Короткий отчёт Али (сообщением, в тот же вечер, **без фото**)

```
Моти в минуту: …  · Лента: ширина … мм, цвет …, непрерывно/с остановками
Возврат стоит: … ₽ · «95%» значит: …
Дефекты: частые …, дорогие …
ХАССП: … (имя), требования: …
Съёмка: … снимков, остановок …, замен …
Брак: … образцов сфотографировано, … взял с собой
Что пошло не так: …
```
