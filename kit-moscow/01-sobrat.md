# 01 · Что взять и что проверить дома

## Взять с собой

Отмечай галочкой при сборе сумки.

**Компьютер и съёмка**
- [ ] Ноутбук + зарядка
- [ ] **SSD DEXP 1 ТБ** + **переходник SATA → USB 3.0** (на SSD уже стоит Linux и вся программа)
- [ ] **Вебкамера** Logitech C920 (или та, что купил) + её кабель
- [ ] Активный USB-удлинитель, если камера не дотягивается до ноутбука
- [ ] **Флешка для резервной копии** (32 ГБ и больше) — копия снимков делается сразу после съёмки
- [ ] Удлинитель-сетевой фильтр на 3+ розетки

**Стенд**
- [ ] Лайтбокс (короб) с отверстием сверху для камеры
- [ ] **Боковая лампа** + её кабель питания (свет сбоку, низко — так видны вмятины)
- [ ] Чёрный матовый коврик / картон на дно
- [ ] **Лист белой бумаги** — кладётся в левый верхний угол кадра; по нему программа следит, не
  поменялся ли свет
- [ ] Малярный скотч — приклеить бумагу и коврик, чтобы не ездили
- [ ] Чёрная ткань — закрыть открытую сторону лайтбокса от света цеха

**Работа с моти**
- [ ] Пищевые перчатки (пачка)
- [ ] Лопатка (пластиковая) — переносить моти, не касаясь верха
- [ ] **2–3 лотка для яиц / маффинов** на 60+ ячеек + маркер — **пронумеровать ячейки 1…60**
  дома, заранее
- [ ] Для «вмятины»: колпачок маркера с круглым концом ~10 мм
- [ ] Для «разрыва»: небольшой нож (их правила могут запретить свой нож — спросить, дадут ли свой)
- [ ] Для «деформации»: плоская пластиковая крышка / тарелка
- [ ] Мягкая кисточка — сметать крахмал с коврика
- [ ] Салфетки

**Опрос и замеры**
- [ ] Телефон + зарядка + пауэрбанк, **на телефоне 10+ ГБ свободно**
- [ ] Рулетка (лучше 5 м) и линейка
- [ ] Распечатанный `03-opros.md` (или открыть на ноутбуке) + ручка + блокнот
- [ ] Термосумка + пищевые контейнеры с крышкой — увезти образцы брака, если отдадут

## Перед поездкой, на телефоне

- [ ] Выключить синхронизацию фото в облако (Google Фото, iCloud, Яндекс Диск, Telegram-автозагрузку).
  Снимки с производства не должны никуда уходить сами.
- [ ] Проверить, что телефон умеет снимать замедленное видео (slow-mo)

## Репетиция дома, накануне (≈ 40 минут) — обязательно

Без неё на месте можно потерять час на то, что решается за 5 минут дома.

1. [ ] Загрузи ноутбук с SSD — `02-noutbuk.md`. Получилось войти и открыть терминал.
2. [ ] Собери лайтбокс, лампу сбоку, бумагу в левом верхнем углу, камеру сверху.
3. [ ] Запусти проверку камеры: `./kit-moscow/kamera.sh` — `05-semka.md`, шаг 3.
4. [ ] Сделай пробный снимок любого светлого круглого предмета (печенье, крышка):
   `./kit-moscow/foto.sh repeticiya` — посмотри снимок: резко? не пересвечено?
5. [ ] Скопируй пробу на флешку: `./kit-moscow/kopiya.sh` — копия проходит без ошибок.
6. [ ] Разбери всё и сложи в сумку по списку выше.

Если что-то из этого не получилось — пиши Али **до** поездки, а не на месте.
