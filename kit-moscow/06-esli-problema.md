# 06 · Если что-то сломалось

Сначала: **спокойно, ничего не удаляй.** Снимки, которые уже сохранены, никуда не денутся.
Если не помогло — сфотографируй экран на телефон и напиши Али.

## Не грузится с SSD

- Ноутбук сразу грузит Windows → не успел нажать клавишу меню загрузки. Выключи и жми клавишу
  **сразу** после кнопки питания, много раз.
- В меню загрузки нет USB:
  1. Переподключи SSD в **другой** порт (лучше синий, USB 3.0), снова.
  2. Зайди в BIOS (обычно F2 или Del при включении) → найди **Secure Boot** → *Disabled* →
     сохранить (F10). Записать, что поменял, чтобы потом вернуть.
  3. Там же: **Fast Boot** → *Disabled*.
- Если Windows спросит ключ **BitLocker** после смены настроек BIOS — верни настройки как было.
  **Не вводи ничего наугад.**

## Камера не /dev/video0

`v4l2-ctl --list-devices` показал у камеры `/dev/video2` (или другое число):

```
nano kit-moscow/station-moscow.yml
```

Строка `device: /dev/video0` → поставь своё число → Ctrl+O, Enter, Ctrl+X.

Камеры нет в списке вовсе → переподключи кабель, другой порт, без удлинителя.

## kamera.sh пишет FAIL

| Сообщение | Что делать |
|---|---|
| `FAIL controls` / `camera reports …` | Переподключи камеру, подожди 5 секунд, запусти ещё раз. Повторилось — пусть сейчас другая программа (Zoom, браузер) не держит камеру |
| `FAIL frames` / `no frame newer` | Кабель / порт. Убери USB-удлинитель, подключи напрямую |
| `camera: … busy` / `Device or resource busy` | Камеру держит другое окно. Закрой все окна программы (Q) и запусти снова. Не помогло — перезагрузи ноутбук |
| `reference patch: varies` больше 3% | Свет мигает или двигается: ткань закрыта? лампа на полной яркости? никто не ходит рядом? |

## foto.sh пишет «попытка 1: gain: set 25, camera reports 24»

Это нормально в первые секунды — программа сама пробует ещё раз. Если все 3 попытки
не удались → закрой (пустая строка + Enter), подожди 10 секунд, запусти снова.

## Съёмка оборвалась (окно закрылось, ноутбук сел, нажал Q)

1. **Не запускай `semka.sh` заново** — он откажется, и это правильно.
2. Запиши в блокнот, на каком шаге остановилось (номер моти и поворот в последней подсказке).
3. Сделай копию: `./kit-moscow/kopiya.sh`.
4. Остальные моти по плану доснимай через `foto.sh`, подписывая **так же, как в плане**:

   ```
   ./kit-moscow/foto.sh dosemka
   ```

   Подписи: `u022-good-0`, `u022-good-120`, `u022-good-240`, затем (если тестовое) повредить
   и `u022-dmg-0`, `u022-dmg-120`, `u022-dmg-240`. Порядок — как в `plan.md`, с того места,
   где остановилось. Контрольные в конце: `c01-pass3-0` и т.д.

Али соберёт всё вместе потом.

## Ноутбук садится

Зарядку — в розетку **до** начала съёмки. Без розетки съёмку не начинать.

## Флешка не находится (kopiya.sh)

Вставь флешку, открой приложение «Файлы» и кликни по ней (чтобы она подключилась), затем снова
`./kit-moscow/kopiya.sh`. Если флешки нет совсем — **не выключай ноутбук**, пока не сделаешь
копию хоть куда-нибудь (телефон через USB тоже подойдёт: папка `data/raw` → телефон).

## Производство запрещает что-то из нашего (нож, лайтбокс в цеху, ноутбук)

Не спорить. Записать, что именно запрещено и почему. Если нельзя снимать в цеху — спросить
отдельную комнату; если нельзя совсем — сделать только `03` и `04`, этого тоже достаточно для
следующего шага.
