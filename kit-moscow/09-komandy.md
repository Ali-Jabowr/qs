# 09 · Все команды: как запускать, что увидишь, что делать

Этот файл — **шпаргалка у ноутбука**. В остальных файлах сказано *когда* что делать; здесь —
*как именно* запустить каждую команду, что должно появиться на экране, и что делать, если
появилось другое.

Команд всего четыре:

| Команда | Зачем | Когда |
|---|---|---|
| `./kit-moscow/kamera.sh` | Проверить камеру (30 секунд) | Дома на репетиции; на месте после сборки стенда |
| `./kit-moscow/foto.sh <слово>` | Отдельные снимки с подписью | Пробные снимки, реальный брак, досъёмка |
| `./kit-moscow/semka.sh` | Съёмка датасета по плану | Два раза: сначала план, потом съёмка |
| `./kit-moscow/kopiya.sh` | Копия всех снимков на флешку | После каждого этапа и в конце дня |

---

## 0. Перед любой командой

1. Ноутбук загружен с SSD (`02-noutbuk.md`), ты вошёл как `qs`.
2. Открой терминал: **Ctrl + Alt + T**. Появится чёрное (или фиолетовое) окно со строкой вроде
   `qs@qs-station:~$` — это значит «жду команду».
3. Раскладка — **`en`** (справа вверху). Если там `ru` — **Alt + Shift**.
4. Набери и нажми **Enter**:

   ```
   cd ~/QS
   ```

   Строка станет `qs@qs-station:~/QS$`. **Все команды ниже — только отсюда.** Если видишь
   `No such file or directory` для `./kit-moscow/...` — значит ты не в `~/QS`: снова `cd ~/QS`.

**Как набирать:**
- Команду пишешь **точно как здесь**: точка, косая черта, без пробелов внутри имени.
  `./kit-moscow/kamera.sh` — правильно. `. /kit-moscow/kamera.sh`, `kamera.sh` — неправильно.
- Подсказка: набери `./kit-moscow/ka` и нажми **Tab** — имя допишется само. Так нет опечаток.
- После команды — **Enter**. Пока команда работает, новой строки `qs@qs-station:~/QS$` нет.
  Когда команда закончилась — строка снова появляется.
- Остановить зависшую команду в терминале: **Ctrl + C**.
- Стрелка **↑** в терминале — повторить прошлую команду (не надо набирать заново).
- Вставить скопированный текст: **Ctrl + Shift + V**.

**Если пишет `Permission denied`** — набери один раз `chmod +x kit-moscow/*.sh` и повтори.

**Если пишет что-то непонятное** — не набирай ничего наугад. Сфотографируй экран телефоном
(весь терминал, чтобы было видно последние строки) и отправь Али. Это не снимок моти — экран
терминала отправлять можно.

## 1. `kamera.sh` — проверка камеры

**Перед запуском:** камера подключена и смотрит в лайтбокс, белый лист лежит в левом верхнем
углу, боковая лампа включена, ткань закрыта. Внутри лайтбокса пусто или лежит один предмет.

**Запуск:**

```
./kit-moscow/kamera.sh
```

**Что будет, по порядку:**

1. Сразу — список камер:

   ```
   == камеры, которые видит ноутбук:
   HD Pro Webcam C920 (usb-0000:00:14.0-2):
           /dev/video0
           /dev/video1
   ```

   Проверь, что под `C920` первая строка — **`/dev/video0`**.

2. Таблица настроек камеры (`control  wanted  reported  status`). В каждой строке справа
   должно быть **`ok`**.

3. Открывается окно **«QS — camera lock test»** с картинкой с камеры и надписью
   `Lock test — frame 1 of 10`. Номер растёт до 10, примерно раз в 3 секунды.
   ⚠️ В окне написано *«Switch the room light on and off twice»* — **НЕ делай этого**, это
   для стенда Али. На производстве свет **не трогаешь**. Просто жди и ничего не двигай.

4. Окно закрывается, в терминале итог:

   ```
   PASS controls: all 8 read back as set
   PASS frames: 10 of 10 captured, 0 failed
   PASS read-back: 10 of 10 frames verified
   PASS freshness: all 10 frames newer than their trigger
   PASS reference patch: varies 0.40% (limit 1%)
   CHECK BY EYE banding — look at the saved frames in data/raw/...
   ```

**Как понять результат:**

| Видишь | Значит | Что делать |
|---|---|---|
| Первые **четыре** строки `PASS` | Камера в порядке | Идти дальше |
| `FAIL reference patch: varies X%`, и X **меньше 3** | Свет чуть плавает, это допустимо | Идти дальше, записать X в блокнот |
| `FAIL reference patch`, X **больше 3** | Свет мигает или что-то двигается | Закрой ткань плотнее, лампа на полную, никто не ходит рядом и не заслоняет. Запусти снова |
| `CHECK BY EYE banding` | Это не ошибка, это напоминание | Открой папку (команда `xdg-open …` в последней строке) и посмотри 2–3 кадра: нет ли тёмных/светлых **полос** поперёк. Полосы есть → лампа мигает: другая лампа или другая розетка |
| `FAIL controls: gain MISMATCH (set 25, reports 23)` (или другое название) | Камера не держит настройку | Отключи камеру, подожди 5 секунд, подключи, снова запусти. Повторилось 2 раза → фото экрана Али |
| `FAIL frames: … failed` | Кадры не приходят | Кабель камеры — напрямую в ноутбук, без удлинителя, другой порт. Снова |
| `camera: … busy` / `Device or resource busy` | Камеру занимает другое окно | Закрой все окна программы (клавиша **Q** в них) и браузер. Снова. Не помогло — перезагрузка |
| `camera: /dev/video0 …` / камеры **нет** в списке шага 1 | Ноутбук её не видит | Переподключи камеру, другой порт. Если камера стала `/dev/video2` — `06-esli-problema.md`, «Камера не /dev/video0» |
| `screen: …` | Не открылось окно | Ты запускаешь не из обычного терминала на рабочем столе? Открой его через Ctrl+Alt+T. Не помогло → фото экрана Али |

Можно запускать сколько угодно раз — ничего не портит.

## 2. `foto.sh` — снимки с подписью

Слово после `foto.sh` — **имя папки** для этих снимков. Используй три:

| Команда | Для чего |
|---|---|
| `./kit-moscow/foto.sh proba` | Пробные снимки, настройка (05, шаг 4) |
| `./kit-moscow/foto.sh brak` | Реальный брак от производства (05, часть Б) |
| `./kit-moscow/foto.sh dosemka` | Досъёмка, если `semka.sh` оборвался (06) |

(дома на репетиции — `./kit-moscow/foto.sh repeticiya`)

**Запуск, например:**

```
./kit-moscow/foto.sh proba
```

**Что будет:**

1. Секунды 3–4 тишина (камера включается). Потом:

   ```
   Снимки идут в data/raw/2026-10-13-moscow-proba/

   Подпись (например brak01-vmyatina), пусто = выход:
   ```

2. Положи моти, закрой ткань, убери руки. Набери подпись **латиницей**, без пробелов
   (например `proba1`), и **Enter**. Через секунду:

   ```
     сохранён 001_proba1.png · белый лист 0.45 (стенд 0.45) · пересвет 0.12%
   ```

3. Снова спрашивает подпись → следующий снимок. **Чтобы закончить — просто Enter на пустой
   строке.** В конце: `Готово: N снимков в data/raw/...`.

**Посмотреть снимки:** `xdg-open data/raw/$(date +%F)-moscow-proba` (вместо `proba` — твоё
слово). Откроется папка, двойной клик по снимку. **Только смотреть**, не редактировать и не
«сохранять как».

**Как понять строку `сохранён …`:**

| Видишь | Значит | Что делать |
|---|---|---|
| `сохранён 00N_… · белый лист … · пересвет 0.xx%` без стрелок | Всё хорошо | Дальше |
| `← ПЕРЕСВЕТ: уменьшить gain` | Больше 1% кадра — белое без деталей | Только на пробе: уменьшить `gain` (05, шаг 4). Во время брака/досъёмки настройки **не менять** — просто записать в блокнот |
| `← белый лист сильно не как на стенде` | Свет у тебя не как у Али, или лист не на месте | Проверь, что белый лист в **левом верхнем углу** кадра и не сдвинулся. Если лист на месте — это просто другой свет: **запиши число** «белый лист 0.xx». Важно не совпасть с Али, а чтобы это число **не менялось** от снимка к снимку |
| `попытка 1: gain: set 25, camera reports 24` | Камера на миг «поплыла» | Ничего, программа пробует сама до 3 раз. Если после этого `сохранён` — всё хорошо |
| `НЕ СНЯТО — проверь камеру` | Все 3 попытки не удались | Enter на пустой строке (выход), подожди 10 секунд, запусти ту же команду снова. Снимки до этого **сохранены**, нумерация продолжится |
| `камера: …` сразу при запуске | Камера не открылась | Как в таблице `kamera.sh` выше (busy / не видна) |

Подпись получилась с ошибкой? Не страшно: просто сделай ещё один снимок с правильной подписью и
запиши в блокнот «снимок 007 — лишний».

## 3. `semka.sh` — съёмка датасета

Запускается **два раза**.

### Первый запуск — план

```
./kit-moscow/semka.sh
```

Через пару секунд:

```
== план съёмки для 2026-10-13-moscow (58 ячеек: c01–c03 и 1–55)
...
ПЛАН ГОТОВ: data/raw/2026-10-13-moscow/plan.md
1) Открой его: xdg-open data/raw/2026-10-13-moscow/plan.md
...
4) Запусти ещё раз: ./kit-moscow/semka.sh 2026-10-13-moscow
```

Открой план (команда из строки 1), разложи моти, жди 30 минут (05, шаг 5).
Камера на этом шаге не нужна.

⚠️ Если день перевалил за полночь или ты запускаешь съёмку на следующий день — запускай второй
раз **ровно той командой из строки 4** (с датой), иначе программа сделает новый план.

### Второй запуск — съёмка

```
./kit-moscow/semka.sh
```

**Сначала четыре вопроса в терминале** — ответить и Enter после каждого:

| Вопрос | Что писать |
|---|---|
| `Вкус / вид моти` | Как называют на производстве, например `klubnika` |
| `Срок годности …, ГГГГ-ММ-ДД` | С упаковки, **строго так:** `2026-10-27` |
| `Время, когда моти взяли с линии [Enter = сейчас, …]` | Если взяли только что — просто **Enter**. Иначе — скопируй формат из скобок и поменяй время, например `2026-10-13T11:40+03:00` |
| `Все 58 моти разложены … (да/нет)` | `да` (или `y`). Любое другое — программа выйдет, ничего не начав |

Если в сроке годности опечатка — программа сразу напишет ошибку и выйдет, **ничего не сняв**:
просто запусти `semka.sh` снова.

**Потом открывается окно съёмки.** В нём картинка с камеры и три строки сверху:

```
u036 · cell 36 · train · 0° — SPACE to shoot
shot 41 of 360 · unit 7 of 58
grey card 0.4512 · drift +0.30% since the first frame
```

- **Строка 1** — что делать сейчас (словарь — `05-semka.md`). В конце `SPACE to shoot` —
  положи моти и нажми пробел для снимка; `SPACE when done` — это действие без снимка (повредить,
  смести крахмал): сделай его, потом пробел.
- **Строка 2** — сколько снято из скольких. Так видно, сколько осталось.
- **Строка 3** — белый лист. **`drift` должен оставаться между −3% и +3%.** Если ушёл дальше —
  что-то поменялось со светом: ткань открыта? лампа сдвинулась? кто-то заслонил? Поправь и
  продолжай. Запиши в блокнот, на каком снимке это было.

В терминале (за окном) при каждом действии без снимка печатается полный рецепт — если строка в
окне обрезана, прочитай её там.

**Клавиши в окне:** **пробел** — снимок / шаг сделан. **Q** — полная остановка (только если всё
совсем плохо). Окно должно быть **активным** (кликни по нему один раз), иначе пробел уходит в
терминал.

**Как закончится — хорошо:**

```
Done: 360 frames and session.yml in data/raw/2026-10-13-moscow
Copy data/raw/2026-10-13-moscow/ to the phone NOW, before anything else (T11)
```

Вторую строку **не выполнять** про телефон — вместо этого нажми любую клавишу в окне (оно
закроется) и сразу **`./kit-moscow/kopiya.sh`**.

**Как может закончиться — плохо:**

| Видишь в терминале | Значит | Что делать |
|---|---|---|
| `camera: u022_… not taken: gain: set 25, camera reports 23 — stopped, frames so far kept` | Камера «поплыла», съёмка **остановилась** | Всё снятое сохранено. Дальше — `06-esli-problema.md`, «Съёмка оборвалась»: копия → `foto.sh dosemka` с того моти, на котором остановилось |
| `stopped after N frame(s) — kept in …` | Нажата Q или закрыто окно | То же самое |
| `!! В … уже есть снимки — эта съёмка уже начиналась` | Ты запустил `semka.sh` после обрыва | Правильно, что отказался. **Не обходить.** → `06`, «Съёмка оборвалась» |
| `shoot: … already has frames` | То же | То же |
| `camera: …` сразу, окно не открылось | Камера не открылась | Как в таблице `kamera.sh`. Потом `semka.sh` снова — снимков ещё нет, можно |
| Окно зависло, `Input/output error`, `Read-only file system` | Отвалился SSD | `06`, «SSD отключился» |

**Копия на середине:** когда в строке 1 появится `control, pass 2` — сними контрольные, затем
открой **второй** терминал (Ctrl+Alt+T), там `cd ~/QS` и `./kit-moscow/kopiya.sh`. Окно съёмки не
закрывай — потом кликни по нему и продолжай.

## 4. `kopiya.sh` — копия на флешку

**Перед запуском:** вставь флешку. Справа на панели / в приложении **Files** она должна
появиться. Если в **Files** она есть, но серая — кликни по ней (она подключится).

```
./kit-moscow/kopiya.sh
```

**Что будет:**

```
== копирую в /media/qs/FLESHKA/QS-moscow
     1,234,567,890 100%   45.2MB/s    0:00:26 (xfr#360, to-chk=0/412)
== проверяю (сравнение содержимого каждого файла)…
ГОТОВО: копия совпадает с оригиналом. Размер:
1.2G    /media/qs/FLESHKA/QS-moscow
```

Ждать, пока не появится строка `qs@qs-station:~/QS$`. Для всей съёмки — несколько минут.
Запускать можно сколько угодно раз: второй раз докопирует только новое.

| Видишь | Значит | Что делать |
|---|---|---|
| **`ГОТОВО: копия совпадает с оригиналом`** | Всё скопировано и проверено | Готово. Флешку можно вынуть — **сначала** в Files нажать ⏏ рядом с ней |
| `!! Флешка не найдена` | Флешка не подключилась | Вставь, подожди 5 секунд, открой Files, кликни по ней. Снова |
| `Найдено несколько дисков: 1) … 2) …` / `Номер флешки:` | Подключено несколько дисков (например, ты открывал в Files диск Windows) | Набери номер той строки, где **имя твоей флешки**, и Enter. Не уверен — **Ctrl+C**, вынь всё лишнее, снова |
| `!! ошибка копирования` / `No space left on device` | Флешка полная или сломалась | Другая флешка, или удали с флешки **свои старые** файлы (не QS-moscow) |
| `!! КОПИЯ НЕ СОВПАДАЕТ` | Что-то записалось неправильно | Запусти `kopiya.sh` ещё раз. Повторилось — другая флешка |
| `rsync: … data/raw/*moscow*: No such file` | Ещё ничего не снято | Нормально, если ты ещё не снимал |

## 5. Порядок за день — одним списком

```
cd ~/QS
./kit-moscow/kamera.sh                 → четыре PASS
./kit-moscow/foto.sh proba             → настроить gain/focus, Enter на пустой строке
./kit-moscow/semka.sh                  → план; разложить моти; 30 минут
./kit-moscow/semka.sh                  → съёмка
     на «control, pass 2», во 2-м терминале:  ./kit-moscow/kopiya.sh  → ГОТОВО
./kit-moscow/kopiya.sh                 → ГОТОВО
./kit-moscow/foto.sh brak              → реальный брак
./kit-moscow/kopiya.sh                 → ГОТОВО
вечером: видео с телефона → Files → QS/data/raw/<дата>-moscow-telefon/
./kit-moscow/kopiya.sh                 → ГОТОВО
Power Off
```

После каждого `ГОТОВО` поставь галочку в блокноте. Если `ГОТОВО` не появилось — ничего не
выключать, пока не появится.
