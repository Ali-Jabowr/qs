# 02 · Ноутбук: загрузиться с SSD и проверить камеру

Твой Windows **не трогаем**. Linux живёт целиком на внешнем SSD: подключил SSD — загрузился в Linux,
отключил — ноутбук как был.

## Загрузка

1. Выключи ноутбук полностью (Пуск → Выключение; если Windows «засыпает» вместо выключения — держи
   Shift при нажатии «Завершение работы»).
2. Подключи SSD через переходник в **синий USB-порт** (USB 3.0). Камеру пока не подключай.
3. Включи ноутбук и сразу часто нажимай клавишу **меню загрузки**:

   | Ноутбук | Клавиша |
   |---|---|
   | ASUS | Esc или F8 |
   | Acer | F12 |
   | HP | F9 (или Esc → F9) |
   | Lenovo | F12 (или маленькая кнопка Novo сбоку) |
   | MSI | F11 |
   | Dell | F12 |
   | Huawei / Honor | F12 |

   **Узнай клавишу своего ноутбука дома, на репетиции.**
4. В меню выбери строку с **USB** / названием переходника / «UEFI: …». Не «Windows Boot Manager».
5. Появится экран входа Ubuntu. Пользователь `qs`, пароль — у Али (запиши его не на ноутбук,
   а на бумагу, отдельно от SSD). Затем пароль шифрования диска, если спросит.

**Если ноутбук сразу грузит Windows:** не успел нажать клавишу — выключи и попробуй снова. Если
в меню нет USB — `06-esli-problema.md`, пункт «Не грузится с SSD».

## Открыть терминал и перейти в проект

Терминал — окно, где пишутся команды. Открыть: **Ctrl + Alt + T**.

```
cd ~/QS
```

Все команды из этого набора запускаются **из папки `~/QS`**. Если не уверен, где находишься —
снова набери `cd ~/QS`.

Вставить текст в терминал: **Ctrl + Shift + V** (не Ctrl+V). Остановить работающую команду:
**Ctrl + C**.

## Проверить, что камера видна

Подключи камеру. Набери:

```
v4l2-ctl --list-devices
```

Должно быть что-то вроде:

```
HD Pro Webcam C920 (usb-0000:00:14.0-1):
        /dev/video0
        /dev/video1
```

Важна первая строка под названием камеры — **`/dev/video0`**. Если там `/dev/video2` или другое
число — `06-esli-problema.md`, пункт «Камера не /dev/video0».

## Выключение

Сначала закрой все окна программы (клавиша **Q** в окне съёмки), затем меню справа вверху →
Выключение. **Не выдёргивай SSD, пока ноутбук включён** — можно потерять снимки.
