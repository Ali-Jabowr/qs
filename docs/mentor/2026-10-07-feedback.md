## Working hypothesis (draft, for Тимофей to own)

> На стенде PatchCore, обученный только на годных моти, находит больше дефектных моти, чем правило
> μ ± 3σ по признакам силуэта, цвета и текстуры, при одинаковом FAR на одних и тех же 30 парных тестовых моти.

- **Решение:** PatchCore (Roth et al., 2022 — сравнение патчей с памятью годных).
- **Baseline:** μ ± 3σ по шести признакам из его таблицы (площадь, соотношение осей, solidity, Hue,
  Saturation, локальная σ по V), μ и σ — по train-моти. Implemented and run **by Тимофей**.
- **Метрика:** recall на 30 дефектных при пороге с FAR ≤ 5% на calib; FAR на 30 годных «до» тестовых.
  Paired comparison (same units) → McNemar exact test; per defect type as detail only.
- **Origin / limitation of the baseline:** global features averaged over the mask barely move for a
  local dent or tear on the top surface; patch-level comparison does.
- **Contribution to the MVP:** if PatchCore doesn't beat μ ± 3σ, the MVP ships geometry-only.
- **Honest limit:** 30 defective units — 30/30 proves recall ≥ 90.5% (one-sided 95% Clopper–Pearson),
  not the client's 95%. Bench defects are self-made → the line stage is separate.
